CIRCUIT NOTES - COMPUTER SYSTEMS REVIEWER

HOW TO OPEN
1. Extract this ZIP completely (right-click > Extract All on Windows).
2. Open index.html in your browser.
3. Keep the JavaScript files, styles.css, favicon.svg, and assets folder together.

No installation, API key, or build step is required.
You can also serve the extracted folder using any static web server.

INCLUDED
- 3 lesson modules and 14 chapters
- 89 key terms, definitions, examples, and flashcards
- Multiple-choice, identification, matching, and mixed quizzes
- Complete coverage mode, immediate feedback, scoring, and missed-term retries
- Interactive learning diagrams, bookmarks, and browser-local progress
- Original lesson PDFs in assets/

SOURCE FILES
index.html   - Website entry point
styles.css   - Responsive design
app.js       - Navigation, study flows, and saved progress
engine.js    - Quiz generation and scoring
data.js      - Lesson content and terminology
visuals.js   - Interactive diagrams and icons
favicon.svg  - Website icon
assets/      - Your three original lesson PDFs

Progress belongs to the browser and origin where you use the reviewer.
Your progress from the hosted website is not included in this ZIP.
